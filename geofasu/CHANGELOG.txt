2.0.3
- Replaced focus/keystroke dictionary export with unattended Win32 menu/dialog automation.
- Dictionary export now requires no user keyboard or mouse interaction.
- Added direct validation of the generated DCF file and clearer dictionary-stage diagnostics.

GEOFASU 2.0.2
==============
- Fixed CADCS.pen UTF-16LE string scanner that was double-escaped in 2.0.1.
- Added ASCII/single-byte fallback scanning for future CADCS rollouts.
- Ranks credentials containing the current YYMM rollout token first.
- Validates discovered rollout credentials against the first real CSDBE during automated dictionary extraction.
- Tries discovered candidates sequentially before declaring authentication failure.
- Keeps password values out of UI messages and user-facing logs.
- Preserves all existing GeoPackage, CSV, UPDCODE, and validation workflows.
