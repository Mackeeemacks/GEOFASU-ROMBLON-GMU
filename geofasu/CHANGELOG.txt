GEOFASU 2.1.5
2026-09-15

Optimized
- Added persistent shared barangay basemap cache for bulk generation.
- Identical raster clips are generated once and reused across PSUs and later bulk runs.
- Uses NTFS hard links for cached basemaps when possible, with file-copy fallback.
- Caches municipality/barangay source layers to avoid repeated MAP LAYERS directory scans.
- Bulk processing now uses staged execution: prepare/index, QGIS generation, then QField packaging.
- QField packages are generated only after all QGIS projects are finished.
- QGIS canvas rendering remains disabled through generation and only the final project is loaded.
- Improved in-window progress reporting with Stage 1/3, Stage 2/3, and Stage 3/3 status.

GEOFASU 2.1.4
2026-09-14

Optimized
- Faster raster clipping using direct geometry transform/buffer operations.
- GDAL raster clipping now uses multithreaded warping.
- Municipality source rasters are cached during bulk runs instead of reopened for every PSU.
- Bulk mode skips per-PSU raster pyramid creation and redraws the QGIS map canvas only once at the end.
- Sample features are indexed by PSU once before bulk generation to avoid repeatedly scanning the full sample layer.
- Bulk generation no longer changes the PSU combo box on every iteration.
- PSU list workbook is opened in read-only mode for faster/lighter loading.

Added
- In-window Pre-Processing progress bar and live status text.
- Bulk Generate button becomes Cancel Bulk Processing while a batch is running.

GEOFASU 2.1.3
2026-09-14

Added
- Added bulk pre-processing for all PSUs in the loaded sample list.
- Added option to create one independent QGIS project for every PSU.
- Added optional automatic QField package creation for every generated PSU.
- Bulk QField packaging reuses the QField options configured in Section 5.
- Added cancellable bulk progress dialog and end-of-run success/failure summary.

Changed
- Bulk processing automatically replaces existing generated QField package folders for processed PSUs after one confirmation.
- QField bulk mode automatically requires QGIS project generation.

GEOFASU 2.1.2
2026-08-24

Changed
- Each PSU generation now starts a new independent QGIS project.
- Previous PSU layers and layer groups are no longer carried into the next PSU.
- Added Save, Discard, or Cancel handling when the current QGIS project has unsaved changes.
- Newly generated PSU project becomes the active QGIS project.
- Removed duplicate temporary processing layer cleanup method.
