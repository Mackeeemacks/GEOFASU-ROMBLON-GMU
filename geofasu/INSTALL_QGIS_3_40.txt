GEOFASU 2.0.0 - QGIS 3.40.x / Windows x64

TARGET
- QGIS 3.40.x 64-bit; validated packaging target is QGIS 3.40.10.
- CSPro 7.7 installed (default Program Files location recommended).

INSTALL
1. Close QGIS.
2. Copy the entire 'geofasu' folder to:
   %APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\
3. Start QGIS.
4. Plugins > Manage and Install Plugins > Installed > enable GEOFASU.

POST-PROCESS CSDBE WORKFLOW
1. Select and read the LFS sample Excel workbook.
2. Enable CSDBE processing only when cross-validation is required.
3. Import CADCS.pen from the CURRENT rollout package.
4. Confirm FIELD VALIDATION OUTPUT\DATA contains every expected CSDBE file.
5. Press Process CSDBE. GEOFASU derives rollout authentication, automatically exports the embedded dictionary through CSPro 7.7 Data Viewer, merges the CSDBE files, and exports the household CSV.
6. Press Load & Validate GeoPackages. GeoPackages are discovered recursively under FIELD VALIDATION OUTPUT\GEOPACKAGES.

IMPORTANT
- Do not reuse a CADCS.pen from another rollout.
- No manual password entry is provided in this production build.
- The bundled sensitive .pyd modules are CPython 3.12 / Windows x64 binaries.


GEOFASU 2.0.3 DICTIONARY AUTOMATION
-----------------------------------
The embedded LFS dictionary is exported unattended through CSPro 7.7 Data Viewer.
No File > Save As interaction is required from the user.
Target: Windows x64, QGIS 3.40.10 (Python 3.12), CSPro 7.7.
